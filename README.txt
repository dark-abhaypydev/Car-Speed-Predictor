CAR SPEED & RPM PREDICTION DASHBOARD

1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py

Features:
- Real-car-inspired circular speedometer and tachometer
- Startup ignition needle sweep on the first dashboard load
- Gear selector buttons and accelerator press/release controls (no slider)
- Demo data or CSV upload
- Data cleaning, feature/target selection, 80/20 train-test split
- Linear Regression prediction and R2 test scores

Note: Demo data is simulated. Predictions are not live vehicle sensor readings.
